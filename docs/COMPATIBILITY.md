# Compatibility Matrix

| Component | Supported baseline | Notes |
| --- | --- | --- |
| Windows | Windows 10 or 11 | Primary tested platform. |
| Python | 3.10 or newer | Tk support is required for the GUI. |
| Siril | 1.4 or newer | The current test environment uses Siril 1.4.4. |
| pySiril | 0.0.15 | Required for the command-pipe integration. |
| FITS | `.fit`, `.fits`, `.fts` | Readable FITS headers and supported image dimensions are required. |
| XISF | `.xisf` | Conversion and metadata behavior depends on valid XISF metadata. |
| Multi-cohort data | Supported | Cohorts are reported and can be exported independently. |
| Multi-substack coverage | Supported | Coverage maps are composed on the final registration canvas. |
| Drizzle | Supported | Increases output size, processing time, and disk requirements. |
| macOS | Supported in principle | Use the Siril executable inside the application bundle and validate with a real smoke run. |

## Report Compatibility

- Current reports use schema version 3.
- Older reports may still open in Run Review and Cropping Workbench.
- Older reports may receive warnings when they lack a manifest, ledger, journal, or integration-time map.
- A report generated by a current run is the preferred input for verification, replay, and cropping.

## Operational Assumptions

- The output directory is separate from the input directory.
- Source backups remain independent of the temporary staging workflow.
- Siril is not already holding a conflicting session when a real run starts.
- The selected Python interpreter has the packages in `requirements.txt` installed.
