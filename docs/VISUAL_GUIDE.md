# Visual Guide

The application is easiest to understand through a small set of screenshots. Keep captures focused on the workflow rather than decorative UI.

## Recommended Captures

1. **Basic setup**
   - Input folder, output folder, frame count, and storage summary.
2. **Preview Run**
   - Integrity PASS/WARN/FAIL findings beside the dry-run command.
3. **Batch Queue**
   - Multiple folders queued for sequential processing.
4. **Run History**
   - Completed reports, automatic single-row activation, two-run comparison, verification, and evidence bundle export.
5. **Run Review**
   - Summary, discarded-frame table, sorting/filtering, and Verify Run result.
6. **Cohort Balance**
   - Cohort retention bars and exposure table.
7. **Quality Explorer**
   - Metric histogram with a recorded threshold line.
8. **Threshold Lab**
   - Interactive keep-best sliders with live replay deltas.
9. **Frame Inspector**
   - Ledger row, source preview, metrics, and rejection reason.
10. **Coverage Inspector**
   - Integration-time preview with crop and canvas statistics.
11. **Visual QA**
   - Preview-level artifact and coverage warnings.
12. **Cropping Workbench**
   - Report loaded, master artifact selected, and numeric crop preview.
13. **Crop Visual Preview popup**
   - Full-master overlay beside the stretched selected-region thumbnail.
14. **Resume Run**
   - Checkpoint detected and resume confirmation.
15. **Tabbed Help**
   - Module-specific explanations for settings, analysis, safety, and recovery.
16. **Main action row**
   - Start/Resume controls with right-aligned checkpoint and run-lock recovery actions.

## Capture Checklist

- Use a current schema-3 report.
- Use a sanitized or representative path if publishing screenshots.
- Keep the report ID and visible frame counts readable.
- Avoid showing private directories, usernames, or unrelated desktop windows.
- Pair screenshots with a short caption explaining the user decision they support.
